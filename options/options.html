🌱 Sprout Editor — Settings

Connect a GitHub account so Sprout Editor can save your changes as commits.

Connect with GitHub

Recommended — sign in and choose which repositories to allow, no copy-pasting required.

Advanced: use a Personal Access Token instead
  1. Go to GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Create a new token scoped to the repositories you want to edit.
  3. Grant it Contents: Read and write permission.
  4. Paste the token below.
