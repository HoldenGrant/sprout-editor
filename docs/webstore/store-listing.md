## Detailed description

```
Sprout Editor turns any static HTML file on GitHub into a point-and-click website builder
— no code, no local dev environment, no pull request required to make a simple change.

HOW IT WORKS
1. Open a .html file on GitHub (e.g. github.com/you/your-site/blob/main/index.html)
2. Click the "🌱 Edit with Sprout" button Sprout Editor adds to the page
3. Click any heading, paragraph, button, or image in the live preview to select it
4. Edit its text, link, colors, size, or spacing from the panel on the right
5. Click "Save to GitHub" — Sprout Editor commits the updated file back to your repo

WHO IT'S FOR
If you (or someone you support) maintains a simple HTML site — a landing page, a small
business site, a personal site — and just wants to fix a typo, swap a photo, or update a
price without opening a code editor, Sprout Editor gets you there in a few clicks.

WHAT MAKES IT SAFE
- Sign in with your own GitHub account (OAuth) and choose exactly which repositories to
  grant access to — nothing else is touched.
- The live preview runs in an isolated, script-free sandbox, so nothing on the page you're
  editing can run unexpected code.
- Nothing is saved until you click "Save to GitHub" and confirm a commit message.
- There is no backend server. Every request goes directly from your browser to GitHub's
  own API — Sprout Editor doesn't operate any infrastructure of its own and never sees
  your data.

WHAT IT EDITS
Headings, paragraphs, list items, buttons, links, and images are detected automatically.
Site owners can also opt individual elements in explicitly with a data-sprout="text" /
"image" / "button" attribute for full control over what's editable.

Full undo/redo (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z), a live-updating preview, and clean commit
messages every time.
```

## Single purpose description (required by Chrome Web Store review)

```
Sprout Editor's single purpose is to let a user visually edit an HTML file stored in a
GitHub repository they have access to, and save the result back to GitHub as a commit.
```
