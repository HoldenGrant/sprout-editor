A Chrome extension for GitHub

Edit any GitHub page by clicking on it.

Sprout Editor turns a plain HTML file on GitHub into something you can point at and change — text, images, buttons, colors — no code editor, no local setup. Save it, and it lands as a real commit.

How it works

Four stages, same as anything that grows.

Sprout Editor follows a page from a raw file to a saved change — nothing skipped, nothing hidden.

Seed

Find the page

Open any .html file on GitHub. Sprout Editor recognizes it and adds an Edit button.

Sprout

Open the editor

Click 🌱 Edit with Sprout. Your page loads in a live preview — safe, isolated, nothing on it can run code.

Leaf

Click and edit

Select any heading, button, or image. Change the text, the link, the color, the size.

Bloom

Save it

Click Save to GitHub. Your change becomes a real commit, on the branch it came from.

Why it's safe to hand off

Built so nothing happens by accident.

Nothing runs but what you click

The preview is sandboxed — the page's own scripts never execute. What you see is layout and content only.

Sign in with GitHub

OAuth device flow, no pasting tokens. You choose exactly which repositories to share, and can revoke access anytime.

Finds text on its own

Headings, paragraphs, buttons, and images are detected automatically — site owners can mark extra elements explicitly, too.

Undo goes all the way back

Every text, link, and style change is tracked. Nothing saves until you click Save and confirm a commit message.

See the whole page at once

A collapsible Layers tree shows every section on the page — click any one, including backgrounds you can't reach any other way, to jump straight to it.

Switch files without losing your place

Pick a different .html file from the toolbar dropdown any time — no need to go back to GitHub and click through again.

Get started

Two minutes, no Chrome Web Store yet.

Sprout Editor isn't published to the Web Store just yet — installing it manually takes about as long as reading this.

  1. Download the extension

    Clone or download the sprout-editor repository from GitHub.

  2. Open Chrome's extensions page

    Go to chrome://extensions and turn on Developer mode (top right).

  3. Load it

    Click Load unpacked, and select the sprout-editor folder you downloaded.

  4. Connect GitHub

    Click the 🌱 icon in your toolbar, then Open Settings → Connect with GitHub — no tokens to copy or paste.

  5. Try it

    Open any .html file on GitHub and click 🌱 Edit with Sprout.

A Chrome Web Store listing is on the way — once it's live, this becomes a one-click install. Until then, the manual load works exactly the same way.
Questions

Before you install

Does this work on any GitHub repo?

Public or private, as long as you connect the GitHub account that has access to it.

Will it break my site's JavaScript?

No. The preview itself doesn't run your page's scripts — that's what keeps editing safe. What gets saved is your real, untouched code with just your edits applied on top.

Is my GitHub token safe?

It's stored only on your device, and only Sprout Editor ever reads it. There's no backend server — every request goes straight from your browser to GitHub.

What if a site uses a JavaScript-driven loading screen or fancy layout tool?

Sprout Editor works best on plain HTML/CSS sites and template-based pages. Sites that build their whole layout with JavaScript may not preview accurately.
